# design_handbook.md

## 1. 设计分析
### 整体风格
本系统界面采用**现代毛玻璃幻彩微光风格（Glassmorphism & Light Theme）**。通过半透明层级、大圆角、细腻的柔和阴影以及明快高饱和度的渐变底色，营造出一种高级、智能、富有亲和力且通透的科技感界面。

### 目标用户感受
- **专业与可信赖**：干净明了的数据图表架构。
- **极简与轻量**：减少了硬质边框框线，通过色彩块面以及高糊玻璃底色区分功能区。
- **沉浸式交互**：中央大面积留给数字人形象，使用户更专注于数字形象本身。

### 视觉重心分析
- **第一视觉重心**：中央区域的二次元古装女性数字人形象。
- **第二视觉重心**：右侧顶部的核心运营指标卡片流及趋势图。
- **第三视觉重心**：左侧的形象配置及维度控制面板。

## 2. 布局系统还原策略
页面整体采用**非响应式大屏精细化三栏式（3-Column Layout）自适应弹性布局**：
- **Header 顶部通栏**：固定高度 `80px`，内部组件使用 `flex; justify-content: space-between; alignment: center;` 双端对齐。
- **Main 主体区域**：外层通过 `flex` 进行横向排布。
  - **左侧控制面板 (Aside)**：固定宽度 `340px`，高度撑满，子级采用 `flex-direction: column` 垂直向下流式排布。
  - **中部预览区 (Section)**：采用 `flex: 1` 动态弹性拉伸，数字人通过绝对定位或大面积居中背景渲染，底部操作条采用 `position: absolute; bottom: 24px;` 的悬浮胶囊设计。
  - **右侧数据区 (Section)**：固定宽度 `620px`，内部通过 Grid 系统与多组 Flex 容器细分（例如指标网格采用 `grid-template-columns: repeat(4, 1fr)`）。

## 3. 颜色系统

### 主色与品牌色
* **品牌主蓝**：`#3B82F6`（用于高亮标签、当前激活状态、主增长趋势线等）。
* **高光微蓝（背景渐变）**：`#E2EDF9` 到 `#F4F7FB` 的线性微渐变。

### 状态色
* **正向增长 / 成功态**：`#10B981`（用于各类超越昨日的数据指标箭头与增幅文本）。
* **负向负荷 / 负面态度**：`#EF4444`（用于情感趋势报告中的负面比例占比）。
* **中性态度**：`#9CA3AF`（用于中间灰度状态表现）。

### 背景与中性色
* **毛玻璃基础色**：`rgba(255, 255, 255, 0.6)`，搭配 `backdrop-filter: blur(20px);`。
* **纯白容器**：`#FFFFFF`（数据卡片实体背景）。
* **主要文本色**：`#1F2937`（清晰易读的高对比度炭黑）。
* **次要/标注文本色**：`#6B7280`（用于较小的单位、昨日对比等说明文案）。

## 5. 组件状态与交互说明

### 1. 胶囊式导航 / 标签页 (Tabs)
* **Default 态**：背景透明，文字 `#4B5563`，悬停 (Hover) 时背景变为 `rgba(255, 255, 255, 0.3)`。
* **Active (激活) 态**：背景变为纯白 `#FFFFFF`（或主蓝 `#3B82F6`），文字随之高亮，并伴随 `box-shadow: 0px 2px 8px rgba(0,0,0,0.05);` 的微浮雕投影。

### 2. 左侧形象配置网格 (Grid Selector)
* **选中状态**：外围包裹一层 `2px` 实线的主蓝 `#3B82F6` 边框，并在右下角或右上角显示一个微型的带有白色勾选标识的圆形 Badge。

### 3. 数据卡片交互
* **静态**：保持微弱的一层阴影 `box-shadow: 0px 4px 12px rgba(0, 0, 0, 0.01);`。
* **Hover 态**：整体往上微移 `1px` 到 `2px` (`transform: translateY(-2px);`)，阴影加深为 `box-shadow: 0px 8px 24px rgba(59, 130, 246, 0.08);`。

## 6. 还原注意事项

### 特殊视觉特效处理
1.  **毛玻璃层级（Backdrop Filter）**：在实现左侧侧边栏、顶部导航以及中央操作条时，务必加上 `backdrop-filter: blur(20px) saturate(180%);`，否则无法完美还原截图中的通透空灵感。
2.  **无边框设计（Border-Free）**：绝大多数卡片不要给它们设定实线 `border`，直接使用背景色块区分。如果必须给毛玻璃添加边角高光线，请使用 `border: 1px solid rgba(255, 255, 255, 0.6);`。
3.  **大圆角规格**：界面内所有大容器组件基本统一采用 `border-radius: 20px` 或 `24px`，小型标签和内部按钮采用 `border-radius: 12px`，严禁出现直角。

### 推荐占位尺寸与三方库选用
* **数字人图片占位**：中央大图推荐预留 `800px × 960px` 比例的透明 PNG/WebP 渲染容器。
* **图表还原**：
    * *用户满意度趋势图*：推荐使用 `ECharts` 或 `ApexCharts` 的 Area 面积折线图，设置 `smooth: true`，开启下方渐变填充 (`linear-gradient(to bottom, rgba(59,130,246,0.3), transparent)`)。
    * *情感趋势报告*：推荐使用标准的 Donut（环形）饼图，设置内半径 `percentage: 70%`。
    * *游客关注点分析*：采用标准的词云图（WordCloud）插件进行随机权重错落排布。
