# design_handbook.md

## 1. 设计分析
### 整体风格判断
本界面属于典型的**二次元沉浸式交互/轻量拟真车载或助手级 UI（Immersive Gaming / Assistant UI Style）**。它将高精度游戏插画作为全屏背景，界面元素高度克制，广泛采用**暗色系高级毛玻璃（Dark Glassmorphic）**，使 UI 容器与精美背景融为一体而不显突兀，最大化突出了数字人主体的交互存在感。

### 目标用户感受
- **强烈的沉浸感**：全景插画背景带来的视觉张力与陪伴感。
- **未来科技感**：高模糊度滤镜配上发光的高光边缘线，呈现赛博朋克与写实交织的轻科幻质感。
- **舒适低疲劳**：专为夜间/暗色环境设计的漫反射毛玻璃介质，有效降低强光对视网膜的刺激。

### 视觉重心分析
- **核心焦点**：正中央的高精绘夜景女性数字人形象。
- **常态交互焦点**：底部高亮且厚实的磨砂玻璃输入主栏以及自带高光梯度的蓝色发送按钮。
- **辅助功能视点**：右上角带有强烈发光描边的 PIP（画中画）看板框，用于展示当前连线或次级状态。

## 2. 布局系统还原策略
页面采用**移动端全屏绝对定位叠层系统（Full-Screen Absolute Stacking Layout）**：
- **底层 (Base)**：背景插画采用 `position: absolute; width: 100%; height: 100%; object-fit: cover;`，确保在各异形移动屏幕上实现完美全贴合填充。
- **顶层动作条 (Header)**：使用 Flex 进行双端两极分化对齐，拉开设置按钮与画中画视窗的距离，不遮挡中间人物面部。
- **下层复合交互流 (Section)**：采用 `position: absolute; bottom: 0;`。内部子构件（对话气泡 -> 快捷问题组 -> 输入框）通过 `flex-direction: column` 垂直向上逆向生长，并设置明确的 `gap` 间距。其中快捷问题采用限宽设计（`width: 60%`），营造出高低错落的自然对话流层次。

## 3. 颜色系统

### 主色与高光渐变
* **激活发送蓝**：`linear-gradient(135deg, #5B92FF 0%, #3867ED 100%)`。此处的饱满纯正科技蓝作为全界面唯一的强色相高亮，起到了绝对的点睛与操作指引作用。
* **高光质感描边**：`rgba(255, 255, 255, 0.25)` 至 `rgba(255, 255, 255, 0.4)`，主要作为磨砂边缘的精细断层线，模拟玻璃侧面的折射光。

### 暗色毛玻璃体系
* **高反光主气泡**：`rgba(255, 255, 255, 0.25)`，通过高饱和度反射和 `backdrop-filter: blur(40px)` 确保白字在复杂背景上依然清晰可读。
* **低反光快捷按钮**：`rgba(255, 255, 255, 0.12)`，更具透明度，避免干扰主内容。

### 文本色阶
* **高对比主字**：`#FFFFFF`（不透明度 100%）。
* **次要非激活字**：`rgba(255, 255, 255, 0.9)`（用于快捷按钮内容）。
* **弱化暗提示字**：`rgba(255, 255, 255, 0.45)`（用于输入框占位符提示信息）。

## 5. 组件状态与交互说明

### 1. 快捷问题列表项 (Quick Action Pill)
* **静止态 (Default)**：半透背景 `rgba(255,255,255,0.12)`，外描边 `1px rgba(255,255,255,0.2)`。
* **点击态 (Active/Pressed)**：背景不透明度瞬间提升至 `0.3`，或整体变色为微弱的品牌蓝调，伴随手机线性马达轻微触觉反馈。

### 2. 蓝调发送键 (Send Circle Button)
* **未输入态 (Disabled)**：若输入框为空，发送键呈现 `opacity: 0.5` 且不可点击。
* **可发送态 (Enabled)**：拥有明显的由上至下的光泽渐变。点击时出现微弱的向内塌陷缩放动画 (`transform: scale(0.92); transition: transform 0.1s linear;`)。

## 6. 还原注意事项

### 移动端高保真还原关键细节
1.  **全面屏安全区适配 (Safe Area Insets)**：
    * 顶部 Header 的 `top: 60px` 在实际开发中需动态累加系统状态栏高度（StatusBar Height）。
    * 底部最后一项组件与 Home 条之间，必须严格控制 `padding-bottom: env(safe-area-inset-bottom);`，以防输入框与系统手势线发生重叠踩踏。
2.  **玻璃物理感重现 (Real-Glass Physics)**：
    * 必须结合 `backdrop-filter: blur(30px~40px)` 与带透明度的背景色才能达到截图效果。如果目标机型性能有限，可采用高斯模糊过后的占位底贴图进行替代降级。
    * 输入框和画中画窗口边缘均带有由强变弱的内阴影或多重边框效果，CSS 实现推荐使用 `box-shadow: inset 0 1px 1px rgba(255,255,255,0.3)` 来增加上边缘的剔透高光。
3.  **异形圆角管理**：
    * 气泡和输入框的圆角非常激进（`40px` ~ `80px` 甚至完全 Pill 胶囊化），实现时切忌为了省事使用常规的小圆角。
