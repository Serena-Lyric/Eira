# UI 响应式适配与功能完善 · 交接说明 (2026-05-29)

## 本次完成内容

### 1. 响应式布局 (Responsive)

#### 管理端 (Admin)
- **桌面端 (> 1400px)**：1920x1080 固定画布 + `transform: scale()` 等比缩放，窗口任意拉伸无错位。
- **平板端 (769px–1400px)**：取消 scale 虚拟画布，改为真实视口流式布局。左右面板宽度自适应缩小，指标卡片切换为 2 列。
- **手机端 (≤ 768px)**：三栏纵向堆叠，所有面板变为 100% 宽度。导航栏精简（隐藏英文副标题），按钮与触控区域扩大。

#### 用户端 (User)
- **桌面端**：1080x2340 画布 + scale 等比缩放。
- **平板端 (769–1200px)**：取消 scale，画布填满视口，字体与按钮等比缩小。
- **手机端 (≤ 768px)**：画布 100% 填满视口，自动适配刘海屏 `safe-area-inset-top`。字体大幅缩小，PIP 小窗从 260px 缩小到 120px，设置面板全屏适配。

### 2. 居中栏自动扩展
- 左栏/右栏收起时，居中 Live2D 渲染区使用 `flex:1` 自动填充剩余空间，不再出现偏移或空白。
- 左栏收起 → 中间区向左扩展；右栏收起 → 中间区向右扩展。两者互不影响。

### 3. 形象预览 (Toggle 双栏)
- 居中底部「形象预览」按钮替代了原来的「动作预览」，点击可同时收合/展开左右两栏。

### 4. 左侧面板优化
- 角色卡片底部 `.card-name` 磨砂标签左右下角均做了 `border-radius: 0 0 16px 16px` 圆角处理。
- 「基础模型」改为「Live2D 模型」，点击可展开下拉模型选择器 (Ayaka_v1 / Hiyori_v3 / Eira_Default / Shinobu_v2)。
- 新增「待机动作（当失去网络连接时）」配置项。

### 5. 右侧面板卡片展开
- TOP5、满意度趋势、词云、情感分析、服务建议五张卡片均支持点击弹出大卡片。
- 展开后右上角有磨砂玻璃圆形 X 关闭按钮，背景为半透明模糊遮罩。

### 6. API 配置页面
- 顶部导航「交互审计」改为「API 配置」。
- 独立页包含：LLM 引擎 / LLM 默认模型 / TTS 引擎 / ASR 引擎 / Embedding 模型 / Web Search / 每日搜索配额 / API Key 状态。
- 系统设置的 LLM/TTS 选项已迁移至此。

### 7. 居中栏按钮调整
- 「动作预览」→「形象预览」(toggle 双栏)
- 「表情调试」→「动作设置」
- 「视角切换」→「更多设置」
