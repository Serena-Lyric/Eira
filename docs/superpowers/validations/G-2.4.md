## 验证步骤

### 第1步：启动全栈

```bash
# 终端 1: Docker 依赖（需先运行）
docker compose -f deploy/docker-compose.dev.yml up -d

# 终端 2: 后端
cd backend
EIRA_DB_DSN=postgresql+asyncpg://eira:eira@localhost:5432/eira \
EIRA_REDIS_URL=redis://localhost:6379/0 \
EIRA_OSS_ENDPOINT=http://localhost:9000 \
EIRA_OSS__SECRET=eira-secret \
EIRA_JWT__SECRET=dev-secret \
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 终端 3: 前端
pnpm --filter @eira/web-user dev
```

### 第2步：确认知识库有数据

浏览器访问 http://localhost:5173/chat → 登录 → 确认知识库已上传文档。

### 第3步：发送 20 条测试问题

按以下列表逐条发送，记录每条回复中：
- 是否包含来源标注（如 `[来源: xxx]` 格式）
- 来源内容是否与回答一致（无张冠李戴）
- 如有 web 链接，检查是否可访问
