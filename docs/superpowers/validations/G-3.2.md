# G-3.2 · 口型同步主观自然度

**日期:** 2026-06-10
**状态:** ⏳ 待 5 名测试者

## 指标

5 名测试者，每人评测 10 段 TTS 语音回复。对口型同步进行 1-5 分评分。平均分 ≥ 3.5/5。

## 前置条件

1. ✅ Live2D 模型就位（mao_pro_zh / hiyori_pro_zh）
2. ⏳ 讯飞 TTS（需 `EIRA_TTS__PROVIDER=xunfei`）
3. 全栈服务运行中
4. 可用的麦克风

## 验证步骤

### 第1步：启动全栈（同 G-3.1）

```bash
export EIRA_ASR__PROVIDER=xunfei
export EIRA_TTS__PROVIDER=xunfei

# 后端
cd backend && uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 前端
pnpm --filter @eira/web-user dev
```

### 第2步：准备评测表

给每位测试者提供以下评分表：

| # | 问题 | 口型匹配度(1-5) | 动作自然度(1-5) | 整体主观评分(1-5) | 备注 |
|---|------|:--:|:--:|:--:|------|
| 1 | 你好，请介绍一下自己 | | | | |
| 2 | 西湖有哪些景点 | | | | |

| 4 | 推荐一个旅游目的地 | | | | |

| 10 | 长城有多长 | | | | |

**评分标准：**
- 1：口型完全不对应，明显不同步
- 2：偶尔有对应，大部分时间不同步
- 3：基本对应，有时延迟或错误
- 4：大部分时间准确，偶有小偏差
- 5：口型完美匹配语音节奏和内容

### 第3步：每位测试者完成评测

1. 打开浏览器 → 登录 → 进入 Chat 页面
2. 确认 Live2D 模型渲染正常
3. 点击麦克风按钮，用语音逐条说出 10 个问题
4. 观察 AI 回答时 Live2D 口型是否与 TTS 语音同步
5. 每听完一条，立即记录评分

### 第4步：汇总计算

- 计算每位测试者的平均整体评分
- 计算 5 位测试者的总平均分
- 记录最差评分的回复供后续改进

## 阈值

- 整体主观评分平均 ≥ 3.5/5
