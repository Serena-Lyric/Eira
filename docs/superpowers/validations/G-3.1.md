# G-3.1 · 端到端语音回路延迟

**日期:** 2026-06-10
**状态:** ⏳ 待讯飞凭证 + 全栈运行

## 指标

端到端 P95 ≤ 5s。分项：
- ASR final ≤ 1.5s
- ASR→LLM 首 token ≤ 1.5s
- LLM 首 token→TTS 首 chunk ≤ 1s

## 前置条件

1. ✅ DeepSeek LLM（已配置）
2. ⏳ 讯飞 ASR（凭证已填，需设 `EIRA_ASR__PROVIDER=xunfei`）
3. ⏳ 讯飞 TTS（凭证已填，需设 `EIRA_TTS__PROVIDER=xunfei`）
4. 全栈服务运行中

## 验证步骤

### 第1步：配置并启动全栈

```bash
export EIRA_ASR__PROVIDER=xunfei
export EIRA_TTS__PROVIDER=xunfei
# 其余环境变量见 G-2.4 文档

cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 第2步：打开前端

浏览器访问 http://localhost:5173/chat → 登录。

### 第3步：使用浏览器 DevTools 测量延迟

1. 打开 DevTools → Network → WS 过滤
2. 点击麦克风按钮开始录音
3. 说出问题（如"西湖有哪些景点"），说完后点击结束
4. 在 WS 消息中记录时间戳：
   - **T0**: voice.start 发送时间
   - **T1**: asr.final 接收时间 → ASR 延迟 = T1 - T0
   - **T2**: 第一个 chat.token 接收时间 → LLM 首 token 延迟 = T2 - T1
   - **T3**: 第一个音频帧接收时间 → TTS 首 chunk 延迟 = T3 - T2
   - **T4**: voice.done 接收时间 → 总延迟 = T4 - T0

### 第4步：重复 10 次

记录 10 次语音问答的延迟数据，计算 P95。

- P95 总延迟 ≤ 5000ms
- ASR final P95 ≤ 1500ms
- LLM 首 token P95 ≤ 1500ms
